📚 QuizMaster – Interactive Learning Platform

QuizMaster is a simple and interactive quiz web application built using HTML, CSS, and JavaScript.
The goal of this project is to help users test their knowledge in a fun and engaging way while also demonstrating core web development concepts.

✨ About the Project

QuizMaster allows users to select a subject and attempt a short quiz consisting of multiple-choice questions.
Each question is time-based, encouraging quick thinking and focus.
At the end of the quiz, users can view their final score along with a detailed review of mistakes.

This project was created mainly to practice JavaScript fundamentals, DOM manipulation, and asynchronous programming.

🎯 Features

Multiple quiz categories:

JavaScript Basics

Science

Mathematics

Timed questions (30 seconds per question)

Automatic question progression when time runs out

Progress bar to track quiz completion

Final score display after quiz completion

Review section showing:

Selected answer

Correct answer

Explanation for each question

Restart option to attempt the quiz again

Clean, modern, and responsive UI

🛠 Technologies Used

HTML5 – For structuring the application

CSS3 – For styling, animations, and responsiveness

JavaScript (ES6) – For quiz logic, timers, and interactivity

⚙️ How the Application Works

The user selects a quiz category from the start screen

Questions are fetched and shuffled using JavaScript

The quiz screen displays questions one by one with a timer

User selects an option and moves to the next question

After the last question, the result screen is shown

The user can review mistakes and restart the quiz

🧠 Concepts Demonstrated

DOM selection and manipulation

Event handling

Promises and async/await

Timers using setInterval and setTimeout

Conditional rendering and dynamic UI updates
